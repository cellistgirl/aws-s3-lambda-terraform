# AWS Serverless Infrastructure with Terraform

Este repositorio contiene el despliegue automatizado de una arquitectura **Serverless** utilizando **Terraform**. El proyecto demuestra la capacidad de gestionar recursos en la nube de forma programática y eficiente.

### 🚀 Componentes de la Arquitectura:
* **Amazon S3:** Configuración de un bucket para el almacenamiento persistente de objetos.
* **AWS Lambda:** Implementación de una función en **Python** para el procesamiento de eventos asincrónicos.
* **Infrastructure as Code (IaC):** Uso de Terraform para el aprovisionamiento de roles de IAM, políticas de seguridad y recursos cloud.
* **Scripts de Automatización:** Incluye herramientas auxiliares en Python para la carga de archivos (`subir_archivo.py`) y pruebas de ejecución.

### 🛠️ Herramientas utilizadas:
* **Terraform:** Para la orquestación de la infraestructura.
* **AWS CLI / LocalStack:** Para la emulación y gestión de servicios cloud.
* **Python 3.x:** Para la lógica de la función Lambda y scripts de soporte.
* **Git / GitHub:** Para el control de versiones y documentación.
